PHP2Shell - Technical Analysis

CVE-2026-109618
Category: Out-of-memory corruption
Mechanism:
OOM interruption can leave request memory in an invalid state.
Request cleanup may subsequently access invalid memory.

CVE-2026-109619
Category: Stale global state / Use-After-Free
Mechanism:
Request-owned memory may be freed while persistent worker state
still references it. A subsequent request may consume stale state.

Affected PHP branches:
8.2.x before 8.2.35
8.3.x before 8.3.36
8.4.x before 8.4.27
